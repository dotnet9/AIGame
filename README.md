# 🥚 词宠岛 WordPet Island

一款面向 3-6 年级小朋友的 **3D 英语学习游戏**：乘着小火车/飞机巡游中国城市，每关一整屏城市地图，走近发光的词宠蛋念出英文唤醒词宠；城里几十块**探索立牌**（大学/美食/风景）点开就是图文小百科。全岛词库覆盖人教版 PEP 3-6 年级 **8 册全部单词与课本短语**（932 词宠）。

> 中文界面 + 英文学习内容 · 语音为主（🎤 跟读）、字母块兜底（🧩 拼词）· 永无失败惩罚

## ✨ 玩法闭环：学习 → 使用 → 复习 → 激励

| 环节 | 玩法 | 学的是什么 |
|---|---|---|
| 🥚 孵化 | 走近发光的词宠蛋 → 听发音 → 点 🎤 读出来（10 秒倒计时自动评分，可 🎧 回放自己的读音；或拼字母块）。读得越准 ⭐ 越多（95 分 +2⭐） | 单词认读 + 发音 |

**🔥 游戏手感**：连续 3 次 PERFECT 触发 **FEVER**——星星翻倍、音乐升调加速；PERFECT 全屏彩带雨 + 手机震动；孵蛋有"摇蛋三下 → 咔嚓裂开 → 星光彩带"仪式感；背景音乐由 WebAudio 程序化实时合成（零下载离线可玩）。

## 🚄 纯城市链条（52 城 · 火车/飞机转场）

- **第一关 = 家乡城市**（默认成都，可在 `data/cities/index.json` 改 `defaultHome`），之后按巡游顺序逐城解锁：成都 → 重庆 → 昆明 → 西安 → 兰州 → 北京(终点)…
- **转场**：全孵过关后小火车/飞机全屏横幅 + 镜头 cinematic 飞行进入下一城
- **北京终点**：大地图 + 金色主题「终点站」徽章 + 抵达横幅「抵达首都北京」+ 烟花仪式
- 每关一整屏城市地图（半径 28~32），全城可走：地标、路网、装饰分区、高台；**不再有农场岛/河/船**

**动态组关**：每关新词约 6（单词+短语混合去重）+ 复习词约 6（已学城市池 seeded 抽取，**seed 稳定跨会话一致**）；蛋约 12 颗（上限 15），其中约 5 颗放在立牌旁，其余散布地标/街角/高台，光柱引导。

**🎁 通关奖励城市**：贵阳/大同/敦煌等 order=0 的城市不进自动巡游路线——**通关北京后解锁**，从「走遍祖国」成就卡点进去自由探索（奖励关=复习 8 词 + 新词 4 词，seed 稳定可重玩）。

**🔗 好友分享链接**：`域名/game?city=chengdu&grade=4&term=s1` 微信一键分享——
- 未注册：自动预填档案（家乡=该城市=第一关，年级册默认按链接）
- 已注册：已解锁的历史城市直接跳过去继续玩；未解锁提示按顺序孵蛋；奖励城市提示「请全部通关后才能玩该城市哦」

## 🏙️ 内容全配置化（data/cities/）

程序只负责渲染与交互，内容全部 JSON 驱动，缺文件自动跳过、空数据兜底（永不因配置缺失崩溃）：

```
game/data/cities/
  index.json                     城市索引（id/名称/大区/巡游顺序/终点城）
  <city>/city.json               城市主体：颜色/历史/图集 gallery/variants/level(半径/蛋数/地标/分区/高台)
  <city>/universities.json       全部本科类大学（985/211/双一流/官网/建校年/排名/一句话历史/bearing 方位）
  <city>/foods.json              美食 8+（图片/简介/bearing）
  <city>/scenes.json             风景名胜 8+（图片/简介/bearing）
  <city>/img/                    预留本地图片目录（默认 Wikimedia Commons 外链，可随时替换）
```

已收录 **52 城**：成都/重庆/昆明/西安/兰州/北京/天津/沈阳/哈尔滨/长春/大连/上海/南京/杭州/苏州/合肥/福州/厦门/南昌/济南/青岛/广州/深圳/武汉/长沙/郑州/洛阳/台北/高雄/台中/台南 等，覆盖 985/211 高校城市与历史文化名城（洛阳/开封/扬州/泉州/绍兴/大同/曲阜…）。

**城市卡片**：顶部真实图片幻灯片轮播（4 秒/张 + 圆点 + 箭头 + 懒加载 + onerror 回退 emoji）；Tab 配置化（`customTabs` 可扩展）；大学卡点击校名跳官网（noopener）、**建校 N 年实时计算**、全球/全国排名（参考值可修正）；美食/风景双列图片卡。

## 🚀 本地运行

Windows 双击 **`run.bat`**（端口 6000，自动选用 Node 或 Python）；或手动：

```bash
cd AIGame
node tools/serve.js 6000       # 禁缓存开发服务器（零依赖，需 Node 14+）
python tools/serve.py 6000     # 等价实现（需 Python 3）
# 浏览器打开 http://localhost:6000/game/
```

排行榜/账号接口：`GET /api/leaderboard`、`POST /api/score` 等，见下方「账号与密码」。纯静态托管时自动降级为本机存档。

### 账号与密码

同一昵称对应同一份学习记录，**密码可留空**；「我的档案」可改昵称/密码。昵称唯一，已设密码的账号登录需验证。

- 接口：`POST /api/register`（重名 409）、`POST /api/login`、`POST /api/update`、`POST /api/score`
- 服务端**不存明文**：`md5(md5(md5(昵称:密码)))` 迭代 3 次，存 `tools/accounts.json`（运行时数据，已 .gitignore）

> ⚠️ **存档结构已随城市链条重构，旧版本存档不兼容**（进度会重新开始）。

## 🧱 技术实现

- **渲染**：Three.js 0.160（CDN importmap，ES Modules）+ 柔和阴影 + ACES + UnrealBloom + 渐变天空 + 粒子
- **美术**：全部程序化建模（`js/models.js`），马卡龙低模；立牌=木杆+圆角板+类别 emoji+中文名 sprite，**共享材质**，几十块/城开销可控
- **数据层**：`js/data.js` 运行时 fetch JSON + 内存缓存 + 缺文件跳过 + 空兜底；`js/cities.js` 配置驱动适配层（路线/变体/测验），**无硬编码城市**
- **组关**：`js/words.js` 的 `chaptersFor(sem, username)`——6 新词 + 6 复习词（seed 由昵称+册派生，跨会话一致）；复习蛋简单模式分支
- **存档**：localStorage + 遗忘曲线（`js/save.js`，孵化池按城市链条新结构）
- **标准美音**：Wikimedia 真人录音 + ffmpeg 变速慢速版（保音高），edge-tts 兜底；932 词/短语已预生成 1862 个 mp3（`game/audio/word/`）；补录用 `node tools/gen-voice.mjs`
- **城市图片**：Wikimedia Commons 外链（`Special:FilePath`），`<city>/img/` 可选本地替换，onerror 回退 emoji
